# Public Port 3001 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make host port `3001` the default public entry point while preserving container port `8080`.

**Architecture:** Docker Compose owns host-to-container publication, so only the host-side default changes. Environment templates and deployment examples must match the new public port; application-internal addresses stay unchanged.

**Tech Stack:** Docker Compose, dotenv, Markdown.

## Global Constraints

- The host-facing default is exactly `3001`.
- The container and Go service continue listening on `8080`.
- Existing `APP_PUBLIC_PORT` overrides remain supported.

---

### Task 1: Change and verify the default public port

**Files:**
- Modify: `.env.example`
- Modify: `docker-compose.yml`
- Modify: `README.md`

**Interfaces:**
- Consumes: `APP_PUBLIC_PORT` from `.env`.
- Produces: default Docker mapping `3001:8080` and matching deployment instructions.

- [ ] **Step 1: Verify the current deployment files still contain host-facing port 8080**

Run:

```bash
rg -n 'APP_PUBLIC_PORT=8080|APP_PUBLIC_PORT:-8080|127.0.0.1:8080|公网IP:8080' .env.example docker-compose.yml README.md
```

Expected: matches in all three deployment files.

- [ ] **Step 2: Apply the minimal configuration change**

Use these exact values:

```dotenv
APP_PUBLIC_PORT=3001
```

```yaml
- "${APP_PUBLIC_PORT:-3001}:8080"
```

Change host-facing README examples to `127.0.0.1:3001` and `服务器公网IP:3001`. Do not change `APP_ADDR=:8080`, `EXPOSE 8080`, or the container health check.

- [ ] **Step 3: Verify public and internal ports**

Run:

```bash
rg -n '3001|APP_ADDR=:8080|EXPOSE 8080|127.0.0.1:8080/healthz' .env.example docker-compose.yml README.md Dockerfile
git diff --check
```

Expected: host-facing values are `3001`; container-only values remain `8080`; diff check exits 0.

- [ ] **Step 4: Commit and push**

```bash
git add .env.example docker-compose.yml README.md
git commit -m "fix: publish studio on port 3001 by default"
git push origin HEAD:main
```
